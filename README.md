# SpatialChat

바탕화면 위에 떠 있는 공간형 실시간 채팅.

채팅방 목록을 오가는 대신, 초대받은 사람들이 각자 **캐릭터**가 되어 같은 바탕화면 위에 함께 있습니다.
캐릭터는 드래그로 옮기고, 말하면 옆에 **말풍선**이 뜹니다. 피그마 멀티플레이어 커서와 비슷한 감각입니다.

배경(다른 앱) 클릭은 그대로 통과되므로 일하면서 켜둬도 방해되지 않습니다.
클릭이 잡히는 곳은 캐릭터·입력창·상단 바뿐입니다.

| | |
|---|---|
| 데스크탑 | Electron — 투명 · 항상 위 · 클릭 통과 오버레이 창 |
| 실시간 동기화 | Firebase Realtime Database — 위치 · 말풍선 · 대화 기록 · 접속 상태 |
| 정원 | 한 공간 최대 5명 (트랜잭션으로 보장) |
| 지원 | macOS (arm64 · x64), Windows, Linux |

---

## 실행하기

Node.js 18 이상이 필요합니다.

```bash
npm install
npm start
```

`src/firebase-config.js`에 동작하는 설정이 들어 있어 바로 실행됩니다.
본인 프로젝트로 바꾸려면 [Firebase 설정](#firebase-설정)을 보세요.

## 사용법

### 입장

캐릭터와 닉네임을 고른 뒤 둘 중 하나를 택합니다.

- **방 만들기** — 안 쓰는 6자리 코드를 발급합니다. 입장 전에 코드가 표시되므로
  친구에게 먼저 알려줄 수 있습니다.
- **참여하기** — 받은 코드를 입력합니다. 코드가 6자리가 되면 그 방을 실시간으로
  확인해서 **참여 인원**을 보여주고, **이미 쓰는 캐릭터는 선택을 막습니다**.
  없는 코드면 입장이 막힙니다.

방은 마지막 사람이 나가면 사라집니다. 그래서 아무도 없는 코드는 "없는 공간"으로 처리됩니다.

### 조작

| 동작 | 방법 |
|---|---|
| 캐릭터 이동 | 내 캐릭터(보라색 이름표) **드래그** |
| 채팅 입력 | **Enter**, 또는 캐릭터 클릭 |
| 다른 앱에서 채팅 | `⌘/Ctrl + Shift + Enter` — 창을 띄우면서 입력창까지 엽니다 |
| 전송 / 취소 | 입력창에서 `Enter` / `Esc` |
| 대화 기록 | 상단 **대화보기** (안 읽은 수 뱃지) |
| 초대 코드 공유 | 상단 **초대코드 복사** |
| 오버레이 숨기기 | `⌘/Ctrl + Shift + Space` |
| 종료 | 상단 **나가기**, 또는 `Esc` **두 번** (2초 안에) |

말은 항상 내 캐릭터에서 나갑니다. 누구를 클릭하든 열리는 건 내 입력창이고, 귓속말은 없습니다.

`Esc`는 한 번에 닫히지 않습니다. 입력창 → 대화 패널 → 종료 확인 순으로 하나씩 닫히고,
종료는 2초 안에 두 번 눌러야 실행됩니다. 실수로 꺼지는 걸 막기 위해서입니다.

한글 입력은 조합이 끝난 뒤에 전송됩니다. 첫 `Enter`로 마지막 글자를 확정하고,
두 번째 `Enter`로 보냅니다.

## 배포

```bash
npm run build                 # 현재 플랫폼
npx electron-builder --mac    # macOS (arm64 + x64 DMG)
```

결과물은 `dist/`에 생깁니다.

### macOS에서 "손상되었기 때문에 열 수 없습니다"

Apple Silicon은 **서명이 깨진 arm64 바이너리의 실행을 거부합니다.** 그런데 electron-builder는
인증서가 없으면 서명을 통째로 건너뛰어, Electron 원본 바이너리의 linker 서명만 남은 채로
리소스가 추가된 상태가 됩니다. macOS는 이걸 "손상됨"으로 보고합니다.

`scripts/adhoc-sign.js`가 패키징 직후 번들 전체를 ad-hoc 서명해 이 문제를 해결합니다.
확인하려면:

```bash
codesign --verify --deep --strict dist/mac-arm64/SpatialChat.app
```

ad-hoc 서명이 공증(notarization)까지 대신하진 못합니다. 받는 쪽에는 여전히
"확인되지 않은 개발자" 경고가 뜨는데, **앱 우클릭 → 열기 → 다시 열기**로 통과합니다.
경고 없이 배포하려면 Apple Developer Program(연 $99)에 가입해 Developer ID 서명과 공증을
붙여야 합니다.

### 전달할 때

**`.app` 폴더를 그대로 보내면 안 됩니다.** 내부 심볼릭 링크가 깨져서 같은 "손상됨" 오류가
재발합니다. 반드시 **DMG**로 보내세요.

카카오톡 등 일부 메신저는 `.dmg` 확장자를 막습니다. 그럴 땐 DMG를 zip으로 한 번 더
감싸면 됩니다 — zip 안에 파일 하나만 들어가므로 디스크 이미지 내부는 손상되지 않습니다.

```bash
cd dist && zip SpatialChat-arm64-dmg.zip SpatialChat-*-arm64.dmg
```

받는 쪽이 그래도 열지 못하면 quarantine 속성 때문입니다:

```bash
xattr -cr /Applications/SpatialChat.app
```

## Firebase 설정

본인 프로젝트로 바꾸려면:

1. [Firebase 콘솔](https://console.firebase.google.com)에서 프로젝트 생성
2. **빌드 → Realtime Database → 데이터베이스 만들기**
3. **프로젝트 설정 → 내 앱 → 웹(`</>`) 추가** → `firebaseConfig` 복사
4. `src/firebase-config.js`에 붙여넣기 (`databaseURL`이 반드시 있어야 합니다)
5. **Realtime Database → 규칙** 탭에 `database.rules.json` 내용을 붙여넣고 게시

5번을 건너뛰면 `messages` 쓰기가 거부되어 대화 기록이 남지 않습니다.

### ⚠️ 보안

현재 규칙은 `.read`/`.write`가 모두 `true`입니다. **6자리 초대 코드만 알면 누구나
그 방의 대화를 읽고 쓸 수 있습니다.**

이 저장소는 공개되어 있고 `src/firebase-config.js`에 `databaseURL`이 그대로 들어 있으므로,
저장소를 찾은 사람은 누구든 데이터베이스에 접근할 수 있습니다.
(Firebase 웹 API 키 자체는 비밀이 아니지만, 열린 규칙과 만나면 문제가 됩니다.)

지인끼리 쓰는 수준이면 실용상 문제없습니다. 그 이상으로 쓰려면 **Firebase 익명 인증**을
붙여 "로그인한 사용자만, 자기 노드만 쓰기"로 조이거나, 저장소를 비공개로 돌리세요.

## 데이터 구조

```
rooms/
  {ROOMCODE}/
    members/                 # 지금 접속해 있는 사람들 (현재 상태)
      {memberId}/
        char   "🐱"
        name   "민지"
        x      0.42          # 화면 가로 비율 (0~1)
        y      0.55          # 화면 세로 비율 (0~1)
        msg    "안녕"         # 현재 말풍선 ("" 면 없음)
        msgAt  1718000000    # 서버 타임스탬프(ms), 말풍선 만료 판정
    messages/                # 대화 기록 (누적)
      {pushId}/
        uid    "-Nx..."      # 보낸 멤버 id — 기록에서 내 말을 가려낸다
        char   "🐱"
        name   "민지"
        text   "안녕"
        at     1718000000
```

- `members`는 **현재 상태**, `messages`는 **누적 기록**입니다. 말풍선은 4초 뒤 사라지지만
  기록은 남습니다.
- 좌표를 비율로 저장하므로 해상도가 다른 사람끼리도 상대 위치가 유지됩니다.
- 접속이 끊기면 `onDisconnect`가 멤버 노드를 지웁니다.

### 기록 수명

| 시점 | 동작 |
|---|---|
| 첫 사람 입장 | 이전 세션 잔재 전부 삭제 — 강제 종료·크래시 대비 |
| 이후 입장 | 24시간 초과분 · 200개 초과분만 삭제 |
| 마지막 사람 퇴장 | 방 전체 소멸 |
| 대화 중 | 최근 100개만 구독해 표시 |

`rooms/$room` 노드에는 쓰기 권한이 없어 방을 직접 지울 수 없습니다. 대신 `messages`를
지우면 `members`가 이미 비어 있으므로 자식 없는 노드가 되고, RTDB가 알아서 방을 없앱니다.

## 프로젝트 구조

```
main.js                 메인 프로세스 — 오버레이 창, 전역 단축키, 클릭 통과 토글
preload.js              렌더러 ↔ 메인 IPC 다리
src/
  index.html            로비(2단계) + 오버레이 마크업
  app.js                렌더러 전부 — 입장, 동기화, 드래그, 말풍선, 대화 기록, 방 정리
  styles.css            투명 배경을 전제로 한 스타일
  firebase-config.js    Firebase 설정
database.rules.json     Realtime Database 보안 규칙
scripts/adhoc-sign.js   빌드 후 ad-hoc 서명 (afterPack 훅)
```

빌드 설정에서 `node_modules`를 제외하고 있습니다. 런타임에 쓰는 모듈은 `electron`과 `path`
(둘 다 내장)뿐이고 렌더러는 Firebase를 CDN에서 불러오므로 번들에 넣을 의존성이 없습니다.
덕분에 asar이 44KB입니다.

## 알려진 제약

- **주 모니터에만 뜹니다.** `getPrimaryDisplay()`만 쓰고 있어 외장 모니터에서 작업 중이면
  오버레이가 보이지 않습니다.
- **나가면 완전 종료됩니다.** 트레이에 상주하지 않아 다시 쓰려면 앱을 새로 실행해야 합니다.
- 캐릭터·닉네임을 기억하지 않아 켤 때마다 다시 고릅니다.
- 오버레이에 포커스가 없으면 `Enter`가 도달하지 않습니다. 그래서 전역 단축키
  `⌘/Ctrl + Shift + Enter`를 따로 두었습니다.
